# eNodeX 控制软件：无板检查与上板设置

2026-11-25 在本机打开课程资料中的 `eNodeX_Control@20210510.exe`，软件窗口可以启动并显示参数，但未连接板卡。该进程以高于自动化工具的 Windows 权限运行，无法由自动化工具操作其输入框；因此没有实际输入或下发参数，也未验证串口、网口及 AD9361 配置成功。

## 无板时界面显示

启动画面显示 RS232 模式、空的串口选择、设备地址 192.168.1.160、单通道发送+接收模式、TXA/RXA。画面初值：发送频率 80000000 Hz，接收频率 104600000 Hz；收发采样率均为 30720000，收发带宽均为 15360000；发射衰减显示 0 dB，接收增益显示 77 dB。这些是软件界面显示的初始值，并非本实验已验证的设备配置，尤其发收频率和项目采样率不匹配。

## 拿到板卡后的示例步骤

1. 确认平台型号、天线端口及课程指定频点，接好 TXA、RXA 天线，再按平台要求供电。不要把射频频点与 FPGA 里的 1.024 MHz 数字 I/Q 音调混淆。
2. 控制连接选其一：RS232 模式下，USB-D 连接设备背面 DEBUG，必要时安装 CH340 驱动，选实际出现的 COM 口；或者按手册通过 ETH 连接并设置同网段地址。`192.168.1.160` 是手册默认示例，实际地址可能不同。点击“连接设备”，先确认成功。
3. 选择“单通道发送+接收”，点击该行的“设置”；选择 TXA/RXA，按界面对应的使能设置操作。
4. 在课程/现场允许的频点，将发送和接收射频频率设置成相同值。手册以 800000000 Hz 为例，另一份实验报告使用 860000000 Hz；具体频点听从课程安排，逐项点击相应“设置”。
5. 将发送、接收采样率分别设为 8192000，逐项点击“设置”；再将发送、接收带宽分别设为 4096000 Hz，逐项设置。这是实验二资料的示例，需要核对软件是否接受及设备实际状态。
6. 发送衰减和接收增益根据实验指导和设备实际信号调整。旧报告 50 dB 发射衰减、45 dB 接收增益仅是该次实验记录，不能保证在当前环境合适；不要将启动界面显示的 0 dB、77 dB 当作已验证设置。
7. 软件配置和 FPGA bit 分别负责 RF 前端与数字链路。当前无线版只有仿真及综合结果，还需完成实现、时序和 bit 生成，并确认 PS7/平台固件配合。下载后以 ILA 查看 TX I/Q、RX I/Q、包络与判决，调整增益与门限；对比解调数据需补偿链路延迟并完成码流对齐。

运行工程仿真：`vivado -mode batch -source wireless/scripts/run_radio_sim.tcl -log wireless/output/simulation.log`。仿真使用理想数字 DDR 信道和人为设置的延迟、增益、相位、扰动，不代替射频软件与实板联调。
